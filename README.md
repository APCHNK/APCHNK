**Frontend Developer** specializing in **Shopify** and **WordPress**, based in Lublin, Poland.

I build fast, maintainable e-commerce stores and content websites: custom Shopify themes in Liquid, bespoke WordPress and Elementor themes, platform migrations, product catalog imports, checkout and payment setup, and third-party integrations. Alongside CMS work, I build interfaces with React, Next.js and TypeScript.

Currently **Senior Frontend Developer at Savellab**, leading frontend decisions for Shopify and WordPress projects.
